# Architecture Decision Records

One file per significant decision. Use the format below and number the files sequentially. Never edit an Accepted ADR's decision. Supersede it with a new ADR and link both ways.

```
# ADR-NNNN: Title
Status: Proposed | Accepted | Superseded by ADR-XXXX
Date: YYYY-MM-DD
Owner: P1–P4

## Context
## Decision
## Alternatives considered
## Consequences
## Questions an examiner might ask
```

The index lives in [`../PLAN.md` §11](../PLAN.md#11-architecture-decision-records).
