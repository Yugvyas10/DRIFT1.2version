# Security

Owner: P2 (Yug Vyas). Every change that touches a boundary below updates this file.

## 1. What we protect

| Asset                                             | Why it matters                                                          |
| ------------------------------------------------- | ----------------------------------------------------------------------- |
| Customer API contracts (OpenAPI specs)            | Often private; they describe internal systems.                          |
| Traffic corpora (recorded requests and responses) | May contain credentials and personal data.                              |
| Reports, evidence and artifacts                   | Contain redacted payloads and contract details.                         |
| API keys, sessions, OAuth tokens, webhook secrets | Grant access to an organisation's data or to GitHub.                    |
| The gate decision itself                          | A forged pass lets a breaking change ship; a forged fail blocks a team. |
| The DRIFT supply chain (dependencies, CI, Action) | A compromised build would run inside every customer's CI.               |

## 2. Trust boundaries

1. **Untrusted input into the engine:** spec files and traffic files come from a pull request, which anyone who can open a PR controls.
2. **CI runner → platform:** reports uploaded with an API key (M5).
3. **Browser → web app:** sessions, RBAC, org scoping (M5).
4. **GitHub → web app:** webhooks, verified by HMAC (M8).
5. **Web/worker → Postgres, Redis, object storage:** internal network. Credentials come from the environment.

## 3. Threats and controls

Status: **Done** = implemented and tested; **Mx** = planned in that milestone (see PLAN §6).

| T5  | Clickjacking, MIME sniffing, referrer leaks                                                         | `X-Frame-Options: DENY`, CSP `frame-ancestors 'none'`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`                                                                                                                                                                                                                                                                                    | **Done** (M0)                        |
| T6  | Script injection in the web app                                                                     | Every page gets a Content-Security-Policy with a per-request nonce and `strict-dynamic` from `src/proxy.ts` (no `unsafe-inline`, no `unsafe-eval` in production, nothing from other origins); the API answers with `default-src 'none'`; an end-to-end test reads the header                                                                                                                                         | **Done** (M5)                        |
| T7  | SSRF through remote `$ref` in a PR-controlled spec                                                  | Remote refs refused by default; local refs confined to `--ref-root` after `realpath` (ADR-0003)                                                                                                                                                                                                                                                                                                                      | **Done** (M1)                        |
| T8  | Resource exhaustion from YAML (alias bombs, huge or deeply nested files)                            | Limits on file size, alias count and nesting depth                                                                                                                                                                                                                                                                                                                                                                   | **Done** (M1)                        |
| T9  | Credentials or personal data from traffic leak into reports, artifacts or logs                      | Redaction on by default before storage or reporting; redacted pointers tracked; errors at redacted values are unknown; canary test (8 planted secrets and personal data reach no output)                                                                                                                                                                                                                             | **Done** (M2)                        |
| T10 | XSS through a crafted spec or payload in the HTML report or PR comment                              | Every value escaped per format; no scripts or external assets; CSP `default-src 'none'` + hashed stylesheet; Markdown fences longer than any backtick run; hostile-report tests for all formats                                                                                                                                                                                                                      | **Done** (M3)                        |
| T11 | Over-privileged GitHub token in the Action or App                                                   | Documented least-privilege `permissions` (contents read; pull-requests write for the comment; security-events write for SARIF); forks' read-only tokens only warn; `pull_request_target` advised against. App: M8                                                                                                                                                                                                    | **Done** for the Action (M4); App M8 |
| T12 | Cross-tenant data access                                                                            | One `requireAuth()` path for routes, pages and server actions; every service filters by the actor's organisation; roles read from the database on each request; other organisations' resources answer 404; integration tests call every organisation-scoped route as an outsider                                                                                                                                     | **Done** (M5)                        |
| T13 | Stolen or leaked API key                                                                            | 256 random bits behind a `drift_` prefix (recognisable to secret scanners); shown once; stored as SHA-256; limited to run permissions and optionally one project; expiry; revocation takes effect on the next request; `lastUsedAt`; creation and revocation audited; the CLI sends it over HTTPS only, never follows redirects with it, and never to storage URLs                                                   | **Done** (M5)                        |
| T14 | Long-lived artifact links                                                                           | Pre-signed URLs: 15 minutes to upload, 5 to download; keys are `orgs/<orgId>/sha256/<hash>`; the server re-reads and hashes an upload before accepting it                                                                                                                                                                                                                                                            | **Done** (M5)                        |
| T15 | Forged or replayed GitHub webhooks                                                                  | HMAC-SHA256 over the raw body with constant-time comparison; delivery-id idempotency                                                                                                                                                                                                                                                                                                                                 | M8                                   |
| T16 | Brute force or abuse of the API                                                                     | Redis-backed rate limits (rate-limiter-flexible, replacing the legacy in-memory map): 600 API calls a minute per key or user, 10 sign-ins per 5 minutes per email, 20 registrations an hour per client address (the last `X-Forwarded-For` entry, which the nearest proxy wrote); 429 with `Retry-After`. They fail open when Redis is down (`/readyz` reports it), plus bcrypt (cost 12) and a 10-character minimum | **Done** (M6)                        |
| T17 | Secrets or personal data in logs                                                                    | Logs carry ids, counts and timings only, never bodies, contracts or traffic; Redis is logged as `host:port`; pino redaction of secret-named fields at two levels; errors logged as name, message and code only (also for plain objects); users see internal failures as a fixed sentence. Tested, and a full local run (worker and web logs) was searched for the API key, passwords and the S3 secret               | **Done** (M6)                        |
| T18 | Local service credentials reused elsewhere                                                          | Compose ports bound to `127.0.0.1`; credentials are labelled local-only and overridable                                                                                                                                                                                                                                                                                                                              | **Done** (M0)                        |
| T19 | Regular-expression denial of service in the redaction detectors                                     | Every quantifier in the detectors is bounded; a timing test runs them on adversarial input                                                                                                                                                                                                                                                                                                                           | **Done** (M2)                        |
| T20 | A secret in a malformed traffic line leaking through error messages                                 | Malformed-line reasons name the field and problem kind only, never the input; tested with a secret in the line                                                                                                                                                                                                                                                                                                       | **Done** (M2)                        |
| T21 | Resource exhaustion from traffic files                                                              | JSONL streamed with a 4 MiB line limit; per-operation and total sample caps; HAR limited to 256 MiB                                                                                                                                                                                                                                                                                                                  | **Done** (M2)                        |
| T22 | Option or command injection through a git revision in `--base <ref>:<path>`                         | `execFile` with an argument array (no shell); refs starting with `-` refused; paths confined to the repository; tested                                                                                                                                                                                                                                                                                               | **Done** (M3)                        |
| T23 | A poisoned local stage cache                                                                        | Keys are content hashes of all inputs; entries are written atomically; a damaged entry is recomputed; the cache is local to the user's checkout (`.drift/`, git-ignored)                                                                                                                                                                                                                                             | **Done** (M3)                        |
| T24 | A report written under someone else's name: a PR comment that copies DRIFT's markers                | The Action updates only a comment with both markers written by its own identity (tested)                                                                                                                                                                                                                                                                                                                             | **Done** (M4)                        |
| T25 | A crafted `pattern` in a pull request's contract makes validation backtrack for a long time (ReDoS) | Job timeouts bound the damage in CI; on the platform a run is stopped after `RUN_TIMEOUT_MS` (10 min) by ending its engine thread, and failed as `timeout`, not retried (tested). Not mitigated in the engine yet (Ajv runs the contract's own patterns)                                                                                                                                                             | Partly done (M6); engine: open (M8)  |
| T26 | Cross-site request forgery against a signed-in user                                                 | The API accepts only `application/json` bodies and allows no cross-origin requests; the session cookie is `SameSite=Lax` and `HttpOnly`; Next.js checks the origin of server actions; a session token is never accepted from the `Authorization` header                                                                                                                                                              | **Done** (M5)                        |
| T27 | Account takeover by signing in with a GitHub account that has the victim's email address            | A GitHub identity never attaches itself to an existing password account: that sign-in is refused (tested)                                                                                                                                                                                                                                                                                                            | **Done** (M5)                        |
| T28 | A stolen session token outliving a password change or a removal from an organisation                | Sessions last 8 hours; each request compares the token's `tokenVersion` with the database and reads the role there; "Sign out everywhere" raises it (end-to-end test replays the old cookie)                                                                                                                                                                                                                         | **Done** (M5)                        |
| T29 | A client claiming an artifact it never uploaded, or storing other content under a hash              | `complete` reads each object from storage and checks its size and SHA-256 (tested with different bytes)                                                                                                                                                                                                                                                                                                              | **Done** (M5)                        |
| T30 | Account enumeration through registration                                                            | Registration answers 409 for a taken address, which reveals that it is registered. Accepted for now; sign-in itself takes the same time for known and unknown addresses                                                                                                                                                                                                                                              | Open (with email verification)       |
| T31 | One tenant learning from the stage cache what another compared, or reading its cached outputs       | Stage outputs and inputs are stored under `orgs/<orgId>/…`; the cache key never crosses organisations (a test compares the same files in two organisations: no hit)                                                                                                                                                                                                                                                  | **Done** (M6)                        |
| T32 | A poisoned or damaged stage cache in object storage changing a result                               | Keys are content hashes of every input and the engine version; a revived Ingest snapshot must hash to its own spec hash; a damaged entry is a miss and is overwritten (tested)                                                                                                                                                                                                                                       | **Done** (M6)                        |
| T33 | Reading another tenant's run events, or exhausting Redis connections with event streams             | The events endpoint authorises like every run route (404 outside the organisation, tested); each web process holds one Redis subscriber shared by all streams; streams end after the final event; history is capped (500) and expires                                                                                                                                                                                | **Done** (M6)                        |
| T34 | A run that never finishes, or a crash that leaves a run "running" for ever                          | Job locks expire and stalled jobs are retried (at most twice), then the run is failed by the dead-letter handler; the per-organisation slot is a lease that expires (tested with SIGKILL)                                                                                                                                                                                                                            | **Done** (M6)                        |
| T35 | Browser uploads (re-run inputs) that exhaust memory or skip the API's checks                        | Server actions check the session and role like every page; each file is at most 25 MiB (server actions accept 26 MB); the action calls the same `rerun` and `completeRun` services as the API, so traffic is read back from storage and its SHA-256 checked, and policy and rules are validated against their schemas                                                                                                | Done (M7)                            |
| T36 | Script injection through contract text, payloads or messages shown in the run pages                 | React escapes every value; no raw HTML is rendered (`dangerouslySetInnerHTML` is not used); the nonce-based CSP (T6) blocks injected scripts                                                                                                                                                                                                                                                                         | Done (M7)                            |
| T37 | A hostile or oversized project policy                                                               | Only members with `projects:write`; at most 64 KiB; parsed with core's safe YAML/JSON parser (T8) and validated against `drift-policy/v1` before it is stored; set and removed in the audit log (tested)                                                                                                                                                                                                             | Done (M7)                            |
| T38 | A copied artifact link outliving the reader's access                                                | Run pages link to `…/artifacts/<kind>`, which checks the session and role on every click and only then redirects (303) to a 5-minute signed URL (T14); an unknown kind is 404 (e2e: no session → sign-in page)                                                                                                                                                                                                       | Done (M7)                            |
| T39 | A DEMO organisation mistaken for real results                                                       | A banner on every page of a `demo` organisation; `demo:seed` only runs the built CLI on `examples/` (PLAN Q12)                                                                                                                                                                                                                                                                                                       | Done (M7)                            |
